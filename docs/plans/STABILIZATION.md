# Stabilization and Testing Phase (planned)

**Status:** Not started. Begins only after the main application modules are substantially complete, and before any production use.
Rule for now: **build first -> stabilize -> comprehensive testing -> production** (`CLAUDE.md`, "Development-first approach").

This file exists so deferred quality work is captured, not forgotten. It is a checklist for that phase, not an instruction to do it now.

## 1. Review
- Review the whole application against `PROJECT_PLAN.MD` and `docs/plans/active/CURRENT.md`; reconcile docs with what was built.
- Identify the critical business workflows (start with: supplier -> contact -> broadcast -> review -> confirm -> observations -> product search -> evidence).
- UI review pass against `docs/design/UI_SYSTEM.md` section 11.

## 2. Automated tests to add
- **Vitest, business logic:** broadcast parser (fixtures from real redacted broadcasts), normalisers, product matching layers, freshness and relative age, money/VAT rules, filters/parsers, audit description.
- **Integration (database-backed):** services against a separate `*_test` database: confirm/ignore/reopen and retraction, latest-per-supplier queries, duplicate handling, transactions rolling back, audit rows, archive rules.
- **Database constraints:** append-only and immutability triggers, CHECK constraints, unique/partial indexes, `Restrict` foreign keys (a prototype of this already ran once; see `docs/architecture/DATA_MODEL.md` section 5).
- **Playwright E2E:** critical journeys only (the workflow above, plus create/edit/archive of suppliers and products, and the review keyboard path).
- **Permissions and role-based access:** authentication exists (ADR 0006): actor attribution, per-role access to screens and actions (see "Added by the Sign-in and Roles milestone" below).
- **Validation and error handling:** every form and action: field errors, conflicts, database unavailable, not found.
- **Edge cases:** very large or malformed broadcasts, duplicate pastes, timezone boundaries, empty states, pagination limits, hostile input in search.

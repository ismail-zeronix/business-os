## The categories

| Category | Who it is for | Main difference |
|---|---|---|
| Business desktop | Offices that buy many and manage them | Reliable, long-lived models with security and management features, business warranty options, and the same model available for a long time |
| Small-business / value desktop | Small offices, shops, reception and basic tasks | Lower price, fewer premium features |
| Consumer / home desktop | Home users and students | Focus on price and looks; lighter security and management features |
| All-in-one (AIO) | Reception, retail counters, clean-looking offices | Screen and computer in one unit; fewer cables and less space; harder to upgrade |
| Mini PC / small form factor | Tight spaces, digital signage, point-of-sale, mounted behind a screen | Very small box; limited expansion; can be business or consumer |
| Tower (standard size) | Users who want easy upgrades and more drives | Larger case; more room for cards, memory and storage |
| Gaming desktop | Gamers and some creators | Powerful graphics card, strong cooling, room to upgrade |

Desktops built for heavy professional work are workstations; see workstations.

## Business desktop versus consumer desktop

| | Business desktop | Consumer desktop |
|---|---|---|
| Purpose | Daily office work across many identical machines | Home use |
| Security and management | Usually a TPM chip and options for remote management | Basic |
| Lifecycle | The same model stays on sale for a long time, so a later order matches an earlier one | Models change often |
| Sizes | Tower, small form factor, mini and all-in-one options | Tower and all-in-one |
| Software | Usually Windows Pro | Often Windows Home |
| Warranty | Options to extend or upgrade the service level | Basic warranty |

Check before quoting: brands rename lines from time to time (for example Dell has been introducing "Dell Pro" names for its business range). If a supplier quotes a name not in this table, do not guess the category; ask.

## How to place an enquiry

1. Ask how many units and who will use them (an office, a reception, a home user).
2. Ask about space (tower, small box or all-in-one), whether a screen is needed, and any ports or cards required.
3. Ask the work it must do, then choose the category and only then look at supplier prices.

## What a workstation is

A workstation is a computer built to run professional software for long hours without failing: 3D design and CAD, engineering and simulation, video editing and rendering, architecture, and data or AI work. It is not just a fast desktop.

## Workstation versus ordinary desktop or laptop

| | Workstation | Ordinary business desktop or laptop |
|---|---|---|
| Graphics | Professional graphics cards that the software makers test and certify for their programs | Basic or consumer graphics |
| Processor and memory | Higher-end processors and much more memory, often with error-correcting (ECC) memory on higher models | Mainstream processors; memory for office use |
| Storage and expansion | Room for several fast drives and extra cards | Limited expansion |
| Build and cooling | Built and cooled for heavy load for long periods | Built for office load |
| Software support | Certified for professional programs (for example CAD and video tools) | Not certified for them |
| Price | Much higher | Lower |

Rule of thumb: if the customer names professional software (CAD, 3D, rendering, simulation, video), ask for the exact programs and the size of their projects, then offer a workstation. A gaming machine is not a substitute when the software vendor requires certified graphics.

## The categories

| Category | Who it is for | Main difference |
|---|---|---|
| Entry workstation (desktop) | Single-user CAD, light 3D, design | The smallest and lowest-priced workstation tower |
| Mid-range workstation (desktop) | Regular 3D, rendering, simulation | More processor power, memory, drives and graphics options |
| High-end workstation (desktop) | Heavy rendering, large simulation, AI and data work | Multiple processors or multiple high-end graphics cards, very large memory |
| Small-form-factor workstation | Tight spaces that still need professional graphics | Compact case; limited expansion |
| Mobile workstation (laptop) | Professionals who work on site or travel | A laptop with a certified professional graphics card, more memory and a stronger build |

Check before quoting: brands rename lines from time to time (for example Dell has been introducing "Dell Pro Max" names for its workstation range). If a supplier quotes a name not in this table, do not guess the category; ask.

## How to place an enquiry

1. Ask which professional software will run on it and the size of typical projects.
2. Ask whether it must be a desktop or a laptop, and how many users.
3. Ask the software vendor's graphics-card requirement, then choose the category and only then look at supplier prices.

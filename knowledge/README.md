# Zeronix Knowledge Base

**Status:** DRAFT
**Purpose:** The written truth about how Zeronix works, for the people who use the app and for any AI module that plans work for Zeronix.

## Who reads this

- **People:** the sales team and admins read it in the app (Knowledge screen). Only an admin will be able to change it.
- **AI modules (later):** every LLM that helps plan or draft work must read this first. It is the same instruction set whichever model is used.

## Rules for any LLM using this folder

1. This folder is the source for how Zeronix operates. If something is not written here, it is **unknown**. Say so and ask a person. Never guess or invent a service, price, customer, supplier, policy or routine.
2. A page whose **Status** is `TO BE FILLED` has no usable facts yet. A `DRAFT` page is not yet confirmed by a person. Only `CONFIRMED` pages are settled policy. Say which kind of page an answer came from.
3. Live business data (products, supplier prices, stock, enquiries, quotations) is **not** in this folder. It lives in the database as observations with evidence. This folder says how to work, not what the current price is.
4. The AI **proposes**, a person **confirms**. Nothing extracted or drafted from these pages becomes fact until a person confirms it.
5. If two pages disagree, do not pick one. Point out the conflict to a person.

## Page template

Each page has a title, a **Status**, a one-line **Purpose**, sections (each a list of facts or questions to answer) and an **Unknowns** list. Replace each `TO BE FILLED` line with the real answer, then change the Status.

## Already established

- Zeronix Technology LLC is a **no-stock reseller**: it does not hold inventory. It buys from suppliers against customer enquiries.
- Supplier prices and stock are **observations** (product, supplier, value, time observed, evidence) and are never a fixed field on a product.
- Pages marked DRAFT were written from the company websites (zeronix.ae, biometricdevice.ae) and the owner. Website statements are marketing claims until the owner confirms them.
- Times are stored in UTC and shown in the Asia/Dubai time zone.
